A recreation of Polarnet by Edward A. Rietman and Robert C Frye.

Polarnet is meant to reliably convert polar coordinates to cartesian coordinates. 
To begin input the desired rounds of training, after that the program will output a plot displaying the models accuracy in relation to training rounds. 
After the brief training, the user has access to a simple cli to test the model. Try using small numbers (-2 < x < 2 ) to improve accuracy.
